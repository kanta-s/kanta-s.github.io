# Kanta Sato — GitHub Pages site

A simple bilingual personal profile for GitHub Pages. The site contains only `Home` and `Resume`; it intentionally omits Publications, Blog, and Visualizations.

## Complete the personal links

Edit `_config.yml` and add the full `twitter` and `booklog` URLs. Until then, both profiles are shown as `URL準備中` without dead links.

Replace `assets/img/profile-placeholder.svg` with a public profile image when ready. Either keep the same filename or update the image path in `index.html`.

## Publishing

The repository name is `kanta-s.github.io`, so GitHub Pages publishes it at <https://kanta-s.github.io/> from the `main` branch.

## Optional local preview

```bash
bundle install
bundle exec jekyll serve
```

The site is intentionally product-neutral: it does not include medicine names, treatment claims, company branding, medical advice, or promotional calls to action.
