# Kanta Sato — GitHub Pages site

A simple bilingual personal profile for GitHub Pages. The site contains `Home`, `Resume`, and `Blog`; it intentionally omits Publications and Visualizations.

## Blog

Blog posts are Markdown files in `_posts`. See [`BLOG_GUIDE.md`](BLOG_GUIDE.md) for secure publishing and editing from a smartphone.

## Complete the personal links

Edit `_config.yml` and add the full `twitter` URL. Until then, the profile is shown as `URL準備中` without a dead link.

The profile photo used on the home page is `assets/img/profile.jpeg`.

## Publishing

The repository name is `kanta-s.github.io`, so GitHub Pages publishes it at <https://kanta-s.github.io/> from the `main` branch.

## Optional local preview

```bash
bundle install
bundle exec jekyll serve
```

The site is intentionally product-neutral: it does not include medicine names, treatment claims, company branding, medical advice, or promotional calls to action.
